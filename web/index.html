Test Case Generator

For anyone without GitHub Copilot in VS Code. Build a prompt with the style rules baked in, run it in any chat LLM, then paste the CSV back here to check it and save it.

Prefer VS Code? Use the /generate-test-case Copilot slash-command instead — see the repo README.
Step 1

Build your prompt

Fill in what you know — the more concrete detail (especially real Polish UI labels), the closer the output. Blank fields are fine; the assembled prompt tells the LLM to ask before guessing. Then copy it into Copilot Chat, Claude, or any chat LLM.

Validate & save
